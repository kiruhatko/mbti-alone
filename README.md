# Дзеркало MBTI — тест для себе

Безкоштовний тест на тип особистості: тип, 5 шкал, 19 граней характеру, когнітивні функції й опис типу.
Повна версія — 91 твердження, швидка — 30. Реєстрації немає, відповіді зберігаються лише в браузері й нікуди не надсилаються:
сторінка не робить жодного мережевого запиту.

Твердження й підрахунок узято без змін з «Дзеркала MBTI» (`src/data.js`, функції в `src/core.js`), тож результат той самий.

```bash
python3 build.py              # src/ → index.html
node tests/e2e.mjs ../MBTI-source
```
